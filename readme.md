# 🏭 Site Institucional - SENAI

Projeto de um site institucional simples e estruturado, desenvolvido como atividade prática para a disciplina de Desenvolvimento Frontend. O objetivo principal foi aplicar conceitos de estruturação de páginas web e navegação entre múltiplos arquivos utilizando HTML5 sem frameworks ou estilos acoplados.

---

## 📁 Estrutura do Projeto

O projeto foi organizado separadamente para manter a semântica e a clareza das páginas, contendo a seguinte estrutura de arquivos:

```text
site-senai/
├── index.html       # Página inicial com a apresentação da empresa
├── servicos.html    # Listagem dos serviços e avisos importantes
└── contato.html     # Informações de contato e tabela de horários

🛠️ Tecnologias Utilizadas

    HTML5 puro (Sem estilização CSS ou scripts JS integrados, focando estritamente na estrutura e semântica das tags).

📄 Páginas Desenvolvidas
1. Início (index.html)

    Título institucional da empresa.

    Menu de navegação para as páginas internas (Serviços e Contatos).

    Imagem ilustrativa representativa do ambiente industrial/tecnológico.

    Subtítulo e texto descritivo sobre a atuação do SENAI.

2. Serviços (servicos.html)

    Listagem ordenada com os principais serviços e cursos oferecidos.

    Seção de avisos importantes direcionados aos estudantes e clientes.

    Link de navegação para retornar à página inicial.

3. Contato (contato.html)

    Informações básicas de contato (E-mail institucional e Telefone).

    Tabela estruturada exibindo os dias e horários de atendimento ao público.

    Link de navegação para retornar à página inicial.

🚀 Como Executar o Projeto Localmente

    Certifique-se de ter um navegador web instalado (Chrome, Firefox, Edge, etc).

    Clone este repositório ou baixe os arquivos da pasta site-senai.

    Navegue até a pasta do projeto e dê um duplo clique no arquivo index.html para abrir a aplicação diretamente no seu navegador.
