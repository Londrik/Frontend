Sobre a Universidade

O ecossistema de desenvolvimento web evoluiu, mas a lógica de blocos estruturados permanece viva. Este projeto demonstra como estruturar uma interface usando a fundação clássica do HTML.

Com apenas um punhado de tags e uma tabela geometricamente alinhada, transformamos arquivos soltos em um ambiente funcional.
